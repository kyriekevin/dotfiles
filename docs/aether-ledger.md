# Aether Ledger

> English · [中文](aether-ledger_zh-CN.md)

Dotfiles owns Aether Ledger's machine prerequisites and private inputs. The Aether Ledger repository
owns collection logic, the generated launchd agent, its dedicated writer worktree, logs, and data.
Keeping that boundary means `chezmoi apply` never carries a stale copy of the scheduler.

## Managed inputs

| Source | Target | Owner |
|---|---|---|
| `Brewfile` | Homebrew packages | dotfiles installs `uv`, `ccusage`, and `zstd` |
| `dot_config/token-activity/node_name.tmpl` | `~/.config/token-activity/node_name` | dotfiles renders `work` or `personal` from `is_work` |
| encrypted Multica source | `~/.config/token-activity/multica.json` | dotfiles decrypts private launch inputs on the work Mac |
| encrypted runtime-role source | `~/.config/token-activity/multica_runtime_roles.json` | dotfiles decrypts private runtime aliases on the work Mac |

The encrypted files are ignored on personal machines. They contain profile, workspace, and runtime
names that do not belong in a public repository.

## Runtime state stays out

Chezmoi does not manage:

- `~/.config/token-activity/multica_dsh_profile`, the durable source binding minted by the collector;
- `~/Library/LaunchAgents/com.kyriekevin.aether-ledger.plist`, generated by the installer;
- `~/.cache/aether-ledger/writer`, logs, DSH sessions, or cumulative data.

Do not add these paths to dotfiles. The private `dshProfile` input seeds a new binding, but the
collector owns the binding after creation and refuses to switch the store silently.

## Reproduce a machine

Apply the dotfiles inputs first, then install from an Aether Ledger checkout:

```bash
chezmoi --source="$HOME/.dotfiles" apply \
  ~/.config/token-activity/node_name \
  ~/.config/token-activity/multica.json \
  ~/.config/token-activity/multica_runtime_roles.json

cd "$HOME/github/Aether_Ledger"
make install
make health
```

`make install` is the only owner of the launchd plist. Re-running it is the supported way to update
the schedule or private environment; do not patch the rendered plist by hand.

## Health check

```bash
make health PACKAGE=aether-ledger
```

The dotfiles check confirms package intent and delegates live installation validation to Aether
Ledger's own `make health`, so its configuration contract is not duplicated here.

Manual checks:

- [ ] `make health` passes in the Aether Ledger checkout.
- [ ] The next scheduled run updates today's `usage/YYYY-MM-DD` branch.
- [ ] No private profile, workspace, runtime, or absolute path appears in a Git diff.
